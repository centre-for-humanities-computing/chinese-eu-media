# Topics

Topic labels for the KeyNMF models fitted to *Nouvelles d'Europe*, phase 3 (21 November 2024 – 26 March 2025). Each label gives the four highest-ranked keywords. The English glosses are ours and are only meant to help orientation. *Primary share* is the percentage of the 5,390 unique articles for which the topic has the highest weight.
